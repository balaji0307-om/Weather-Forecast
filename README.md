# 🌦 Weather Forecast App

A responsive weather forecasting web application built with React and Weather APIs.

## ✨ Features

- Real-time weather updates
- Search weather by city
- Responsive UI design
- Dynamic weather data
- API integration
- Clean and modern interface

## 🛠 Tech Stack

### Frontend
- React
- JavaScript
- CSS

### API
- Weather API

### Deployment
- Render
